## Question 1

According to the Red Hat definition, what three areas does DevSecOps integrate to create a shared responsibility for security?

A. Design, Software, and Operations
B. Development, Security, and Operations
C. Deployment, Security, and Optimization
D. Documentation, Security, and Orchestration

**Correct Answer:** B

**Explanation:** DevSecOps stands for development, security, and operations, integrating these areas as a shared responsibility throughout the entire IT lifecycle.

---

## Question 2

What is the ultimate goal of shifting security left in a DevSecOps environment?

A. To move security testing to the very end of the release cycle
B. To ensure vulnerabilities are identified and fixed earlier in the process
C. To reduce the number of developers on a project
D. To eliminate the need for automation tools

**Correct Answer:** B

**Explanation:** Shifting security left ensures that security activities happen earlier in the process so that vulnerabilities are identified and fixed before they become critical issues.

---

## Question 3

How do high-performing DevSecOps teams view the role of security?

A. As a separate gateway that code must pass after development
B. As a bottleneck that slows down fast-moving environments
C. As an afterthought addressed during the maintenance phase
D. As a part of the delivery process, not something separate from it

**Correct Answer:** D

**Explanation:** The best DevSecOps teams view security as an integral part of the delivery process rather than a separate or isolated step.

---

## Question 4

Which core principle of DevSecOps focuses on reducing human error and ensuring security checks happen consistently without slowing down developers?

A. Integration of Security
B. Automation
C. Collaboration
D. Continuous Feedback

**Correct Answer:** B

**Explanation:** Automation allows security checks, such as static code analysis and dependency scanning, to happen consistently and efficiently within CI/CD pipelines.

---

## Question 5

The principle of **Collaboration** in DevSecOps is primarily about:

A. Hiring more security specialists to oversee developers
B. Ensuring that only the operations team handles deployment
C. Breaking down silos and sharing responsibility for security across all teams
D. Using as many different security tools as possible

**Correct Answer:** C

**Explanation:** DevSecOps thrives on breaking down silos between development, operations, and security teams so that everyone "owns" security.

---

## Question 6

Which of the following is described as the “eyes and ears” of DevSecOps?

A. Automation
B. Threat Modeling
C. Continuous Feedback and Monitoring
D. Secure Design Reviews

**Correct Answer:** C

**Explanation:** Monitoring tools act as the "eyes and ears" by detecting misconfigurations and anomalies as they occur, providing real-time insight into security posture.

---

## Question 7

In contrast to traditional security practices, DevSecOps is focused on:

A. Reaction
B. Manual inspection only
C. Prevention
D. Post-deployment patching as the primary strategy

**Correct Answer:** C

**Explanation:** Traditional security is often reactive, while DevSecOps is about prevention by integrating security from the start.

---

## Question 8

Which of the following is an example practice for the **Integration of Security** principle?

A. Centralized dashboards and metrics
B. Threat modeling and secure design reviews
C. Shared Slack channels for all teams
D. Automated SAST and DAST scanning

**Correct Answer:** B

**Explanation:** Integrating security involves building it into every phase of the SDLC, with practices like threat modeling and secure design reviews.

---

## Question 9

According to the "Putting It All Together" summary, what is the primary purpose of **Continuous Feedback**?

A. To build security into every SDLC phase
B. To align teams across different disciplines
C. To reduce human error and speed up delivery
D. To improve continuously through visibility

**Correct Answer:** D

**Explanation:** Continuous feedback provides visibility into the security posture, allowing teams to respond quickly and improve over time.

Which recommended book explains the cultural and organizational transformation necessary for successful DevOps and DevSecOps adoption?

A. Securing DevOps
B. The Phoenix Project
