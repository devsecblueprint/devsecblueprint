## Question 1

In the narrative of **The Source**, why is a Pull Request (PR) considered a critical security checkpoint?

A. It is the only way to save code to a local machine
B. It acts as a human firewall by requiring peer review before code is merged
C. It automatically deletes old versions of code to save space
D. It encrypts the developer's laptop hard drive

**Correct Answer:** B

**Explanation:** Pull Requests facilitate peer review, ensuring that a second pair of eyes inspects code for vulnerabilities or logic errors before it ever reaches the shared repository.

## Question 2

Regarding **The Logic**, why should a DevSecOps professional understand programming concepts like loops and conditionals?

A. To rewrite the Linux kernel from scratch
B. To identify potential vulnerabilities like SQL injection or logic-based DoS
C. To design marketing websites for the application
D. To avoid using Git in the workflow

**Correct Answer:** B

**Explanation:** Code literacy allows security professionals to "read" the logic of an application, helping them spot where data flow might be hijacked or where inefficient code could cause a system crash.

## Question 3

In **The Foundation (Linux)**, what does the phrase "Everything is a file" imply for a security engineer?

A. Every user must carry a physical file folder
B. Security tools only work on .txt files
C. Hardware, processes, and settings can be inspected and managed through the command line
D. Databases are not allowed to be used on Linux systems

**Correct Answer:** C

**Explanation:** This Linux philosophy allows engineers to use standard command-line tools to monitor processes, network connections, and system hardware as if they were simple files.

## Question 4

On **The Highway (Networking)**, what is the primary security benefit of using HTTPS over HTTP?

A. It makes the website load faster by bypassing the firewall
B. It provides a "sealed envelope" by encrypting data in transit
C. It allows the website to function without an IP address
D. It prevents the server from needing a password

**Correct Answer:** B

**Explanation:** HTTPS uses TLS/SSL encryption to ensure that data traveling across the network "highway" cannot be read by unauthorized parties if intercepted.

## Question 5

In **The Guardrail (Security Fundamentals)**, which pillar of the CIA Triad ensures that data has not been tampered with?

A. Confidentiality
B. Availability
C. Integrity
D. Authentication

**Correct Answer:** C

**Explanation:** Integrity is the security principle that ensures information remains accurate and unchanged by unauthorized users during storage or transit.

## Question 6

According to **The Philosophy (DevOps)**, what is the "Shift Left" approach?

A. Moving security testing to the end of the development cycle
B. Integrating security as early as possible in the development process
C. Replacing all developers with security specialists
D. Moving all servers to a different geographic region

**Correct Answer:** B

**Explanation:** "Shifting Left" means moving security concerns to the "left" (the beginning) of the timeline, catching issues during the planning and coding phases rather than after deployment.

## Question 7

In **The Assembly Line (CI/CD)**, what is the role of "Continuous Integration"?

A. Manually checking code once a year for bugs
B. Automatically building and testing code every time a change is committed
C. Buying new hardware for the office every month
D. Writing the application's documentation by hand

**Correct Answer:** B

**Explanation:** Continuous Integration (CI) ensures that every small change to the code is automatically built and tested, providing immediate feedback on whether the new code is safe and functional.

## Question 8

In **The Horizon (Cloud)**, what is the "Shared Responsibility Model"?

A. The provider is responsible for everything, including your data
B. You are responsible for everything, including the physical data center
C. The provider secures the cloud infrastructure, while you secure what you put in it
D. No one is responsible for security in a cloud environment

**Correct Answer:** C

**Explanation:** Cloud security is a partnership; the provider (like AWS/Azure) secures the "house" (hardware/hypervisor), but you are responsible for the "locks" (data, IAM, and apps).

## Question 9

Why is **Infrastructure as Code (IaC)** considered a game-changer for Cloud Security?

A. It allows you to build data centers manually using a mouse
B. It allows infrastructure to be version-controlled, audited, and tested like software
C. It eliminates the need for networking knowledge
D. It makes the cloud free to use

**Correct Answer:** B

**Explanation:** IaC allows security engineers to write scripts that define the environment, meaning the entire network can be scanned for misconfigurations before it is even built.
