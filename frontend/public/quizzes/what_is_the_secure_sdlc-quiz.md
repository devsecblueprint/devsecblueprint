## Question 1

What is the structured process used for developing software applications called?

A. DevSecOps
B. Secure SDLC
C. SDLC
D. Agile Methodology

**Correct Answer:** C

**Explanation:** The Software Development Life Cycle (SDLC) is a structured process used for developing software applications through planning, design, development, testing, deployment, and maintenance.

---

## Question 2

What is a major security disadvantage of the traditional SDLC model?

A. It involves too many planning phases.
B. Security is often treated as an afterthought and addressed late in the process.
C. It requires expensive automated tools for every stage.
D. It focuses too heavily on non-functional requirements.

**Correct Answer:** B

**Explanation:** In a traditional SDLC, security is often treated as an afterthought and is addressed well into the maintenance phase, making it costly and disruptive to fix issues discovered late.

---

## Question 3

In the context of the Secure SDLC, what does the term "Shift-Left" primarily mean?

A. Moving development tasks to the left side of the calendar.
B. Shifting all testing responsibilities to the operations team.
C. Integrating security considerations into every phase of the process from the start.
D. Prioritizing performance over security in early stages.

**Correct Answer:** C

**Explanation:** Shifting-left in the SSDLC means moving security from the end of the lifecycle and integrating it into every phase within the SDLC to catch vulnerabilities early.

## Question 4

Which security activity is considered "very important" and should occur during the **Planning and Requirements Gathering** phase?

A. Static Application Security Testing (SAST)
B. Threat modeling
C. Container hardening
D. Penetration testing

**Correct Answer:** B

**Explanation:** During the planning phase, crucial security activities include threat modeling, conducting risk assessments, and compliance mapping.

---

## Question 5

During the **Design** phase of the SSDLC, which of the following is a primary security focus?

A. Writing the actual code securely.
B. Identifying attack vectors and ways to mitigate them.
C. Applying security patches to production servers.
D. Monitoring for new vulnerabilities post-release.

**Correct Answer:** B

**Explanation:** The design phase involves making architectural decisions with security as a priority, such as defining security controls and identifying attack vectors to mitigate.

---

## Question 6

In which phase do activities like **SAST scans** and **dependency vulnerability checks** primarily take place?

A. Planning
B. Design
C. Development
D. Testing

**Correct Answer:** C

**Explanation:** The development phase is where secure coding practices are applied, including code reviews, SAST scans, and checking dependencies for vulnerabilities.

## Question 8

Which of the following is a security activity that occurs during the **Deployment** phase?

A. Threat modeling
B. Executing SAST scans
C. Container hardening and scanning
D. Patch management

**Correct Answer:** C

**Explanation:** Security during deployment includes reviewing configurations, container hardening and scanning, and ensuring least privilege access controls.

---

## Question 9

Developing an **incident response plan** and implementing **continuous monitoring** are activities associated with which phase?

A. Design
B. Development
C. Testing
D. Maintenance

**Correct Answer:** D

**Explanation:** The maintenance phase focuses on continuous security, monitoring for new vulnerabilities, patch management, and developing incident response plans.

## Question 10

According to the overview, what is a key benefit of using a Secure SDLC?

A. It eliminates the need for manual code reviews.
B. It reduces cost and eliminates the overhead of releasing vulnerabilities into production.
C. It ensures that software is completely free of bugs.
D. It allows security to be addressed by only the operations team.

**Correct Answer:** B

**Explanation:** Finding and figuring out security issues earlier in the Secure SDLC helps save cost and eliminates the potential of releasing vulnerabilities into the wild.
